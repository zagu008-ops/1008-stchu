# 真实本地酒馆跨楼层验收

日期：2026-10-15。使用真实 SillyTavern 1.19.0、当前安装的 cos姬 查看器与数据库读取逻辑；没有替换查看器函数或伪造浏览器接口。

## 环境

- 独立测试实例：`http://127.0.0.1:18000/`，仅监听本机。
- 独立数据：`/tmp/cosji-real-tavern-gallery/data`，未修改原酒馆聊天、预设或账号。
- 专用角色 `Cosji Gallery Test`，81 楼测试聊天。
- 第 0 楼：A1；第 40 楼：B1、B2；第 80 楼：C1。PNG 为本地生成的彩色编号测试图。
- 图片存入真实酒馆插件的服务器缓存配置，由原生 getMergedAndSortedImages / getItemImg 读取。

## 实测结果

1. 打开测试聊天后，页面只渲染了第 80 楼生图，DOM 中只有一个 image-tag-button；第 0、40 楼仍是未处理的文本标记。
2. 点击 C1 打开查看器，计数 `1 / 1 · 图组 3/3`。
3. 连续点上一张，真实中心图片路径依次为 B2、B1、A1，计数依次为 `2 / 2 · 图组 2/3`、`1 / 2 · 图组 2/3`、`1 / 1 · 图组 1/3`。
4. 连续点下一张，真实中心图片路径依次为 B1、B2、C1。
5. 切换到 393×852 手机宽度，复现旧样式隐藏按钮：`.st-chatu8-preview-nav { display: none !important; }`。
6. 移除窄屏强制隐藏，保留最小 44×44 触控尺寸，由查看器自身控制可见性。重载实际酒馆后，上一张按钮可见，点击后从 C1 正确进入 B2，中心路径 `/cosji-gallery-fixtures/B2.png`、计数 `2 / 2 · 图组 2/3`。
7. 29 组自动化回归通过。

结论：当前聊天缓存索引支持跨未渲染楼层双向切图；手机宽度不再隐藏左右按钮。此次手机验证是窄屏浏览器按钮交互，未声称覆盖实体手机触摸手势或远端酒馆部署。
