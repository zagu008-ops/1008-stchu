# cos姬

SillyTavern 图片生成扩展，基于 st-chatu8 3.1.4。原作者与授权信息见 LICENSE 及源码。

## 分支

- `old`：保留本仓库原版本，提交 `944a3f8`，包含原有 1008-stchu 功能。
- `main`：2026-10-11 本地开发的 cos姬 版本。旧版专有功能保留在 `old`，主分支对应当日实际使用的新版代码。

## 安装

内部设置 ID 为 `1011-st`，资源路径自动适配安装目录；已有 `1008-stchu` 安装可以直接更新 `main`。新安装可在酒馆用户扩展目录中执行：

```sh
git clone --branch main https://github.com/zagu008-ops/1008-stchu.git 1011-st
```

已有同名目录时，先备份并使用独立目录检查，避免直接覆盖。启用 cos姬 后停用原 st-chatu8，刷新酒馆。

本仓库只保存插件代码，不包含密钥、聊天、连接配置、用户预设或图片缓存。

## 新版功能

- 沿用酒馆连接配置，在插件中独立选择 LLM 模型。
- 角色与服装两级预设、全部公共与角色公共提示词、默认 LoRA 命名预设。
- Civit Trigger Words 批量导入、去重、地址记忆与缓存缩略图。
- ComfyUI 连接预设、完整模型列表自动读取、跨地址 LoRA 检测和预设复制。
- 聊天悬浮窗快速切换角色、服装、固定尺寸或 AI 尺寸。
- 可选“预设服装覆盖 LLM 服装”；过滤常见服装 Tag，保留场景和动作。陌生标签可能需要手动检查。
- 生图任务历史、最终正负向 Tag、替换与合并过程、诊断导出、分页、可撤销清理。
- 正文生图 XML 格式兼容、提示进度清理、WeiLin 多 LoRA 标签兼容、空工作流恢复。

## 3.1.4-cosji.3 更新

- 生图历史图片查看器：大图、左右切图、键盘导航、仅看图 / 看图＋Tag、全屏和下载。
- 记录原始及最终正负 Tag，在提交前去除重复 Tag 和重复 LoRA；相同 LoRA 后出现的权重优先。
- 核对当前 ComfyUI 的节点、模型和可选参数，缺失项直接显示具体原因；失败后释放生成队列。
- 原生 LoRA 工作流支持 MODEL/CLIP 权重、model-only 模式及两段 XL 采样的独立二次种子。
- 参数面板区分基础尺寸和实际输出尺寸，旧图查看时读取真实像素尺寸。
- 公共服装支持导入图片，由支持图片输入的已配置 LLM 反推可编辑的服装模板。

历史任务的图片保存在当前浏览器的 IndexedDB 中，不写入酒馆设置或诊断导出。切换浏览器、清理站点数据后，历史文字记录仍可能存在，但该浏览器未保存的图片不可查看。

可选本机配置使用 `cosji-connection-repair.local.json` 和 `cosji-workflow-package.local.json`，默认不随仓库分发，已加入 Git 忽略。前者只针对指定地址恢复已确认失效的连接配置；后者按版本安装指定工作流，并备份被替换的设置。没有这些文件时，不执行配置恢复或工作流安装。更新安装包时保留已有尺寸、采样参数和种子设置。

`cosji-xl-workflow.mjs` 提供两段 XL 图的 API 转换逻辑：展开隐式连接，保留潜空间放大与二次采样参数，默认每次请求输出一张。它不安装任何模型或 ComfyUI 自定义节点。

## Civit 角色与服装自动导入（beta）

新增按钮“导入角色 / 服装并下载 LoRA”。需在目标电脑安装 [ComfyUI Civit Down](https://github.com/zagu008-ops/comfyui-civit-down)，并在酒馆安装其 `sillytavern-server` 接入组件、启用 `enableServerPlugins` 后重启。首次在 ComfyUI 电脑本机浏览器授权，酒馆配对一次；手机复用目标电脑的授权。

入口包含版本选择、公开资料 LLM 识别、作品名称查询、角色/服装词组纠正、预览图与统一确认。下载和 SHA256 校验成功后保存预设，不改变当前应用服装。任务留在服务器，关闭页面后下载继续，重新打开可恢复并保存；可取消和重试。

只支持同人单角色 LoRA。使用当前“生图”请求类型配置的文本 LLM，只发送公开模型资料，不发送聊天。基础模型不匹配时停止；未知兼容性需要人工核对。Pony、Illustrious、Anima、普通 SDXL 分开判断。配对凭据保存到酒馆原生秘密存储，账号凭据留在 ComfyUI。此版仍需完成浏览器、手机和另一台电脑安装验收，不能以自动化测试代替实际使用验证。
